🛡 Essential Security Tools

Linda akaunti zako, kagua social media, na chunguza link kabla hujabonyeza.

Password Strength

Pima nguvu ya password bila kuituma kwa huduma ya nje.

🌐

Quick URL Safety

Chunguza URL kwa analysis ya ndani kabla ya kuifungua.

🧪

VirusTotal URL Analysis

Kwa URL inayotia shaka, mfumo unaweza kutumia VirusTotal kuona detections kutoka scanners nyingi. VirusTotal inaruhusu URL scan na report ya URL.

VirusTotal API haijawekwa kwenye server. Admin anahitaji kuweka VIRUSTOTAL API key.
Usifungue link suspicious mwenyewe. Kagua kwanza; ukithibitisha tukio, tumia Report Incident.
📱

Social Media Security Check

Weka username/handle yako. Mfumo utakuelekeza kwenye profile yako halisi na security settings rasmi za platform. Haujifanyi kama platform wala hauombi password yako.

Ikiwa profile yako ina dalili za takeover, fake account, suspicious login au phishing, badilisha password kupitia security page rasmi na kisha Report Incident.
🚨

Report a Security Incident

Ukipata phishing, fake account, hacked social account, scam link au tukio jingine, usiishie kwenye check — liripoti kwa timu.
